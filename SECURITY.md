# Security

`tastr-engine` is a library and a command-line program that analyze audio on the machine they run on. They open
no network connections and need no secrets. The input they parse is audio files, so the likeliest problems are
crashes or excessive memory use on malformed files.

## Reporting a vulnerability

Please report security problems privately through GitHub: on this repository's **Security** tab, choose
**Report a vulnerability**. Don't open a public issue for them.
